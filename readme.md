# E-Commerce Growth Overview Dashboard

A lightweight Streamlit dashboard for understanding e-commerce growth using sales and order data.

Built with Python, Pandas, NumPy, Plotly, and Streamlit, the app lets you upload a CSV or Excel file and quickly explore business performance through key growth KPIs and visualizations.

## Features

- CSV and Excel upload support (`.csv`, `.xlsx`, `.xls`)
- Automatic schema detection and column mapping
- Revenue, orders, customers, and AOV growth analysis
- Daily, weekly, monthly, and quarterly trend views
- Data cleaning for common formatting issues
- Interactive charts for revenue, orders, and AOV trends
- Docker support for containerized deployment

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- OpenPyXL / xlrd
- Docker

## Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/Ramayanah/E-Com-Growth-Overview-Dashboard-v1.git
cd E-Com-Growth-Overview-Dashboard-v1
```

### 2. Create and activate a virtual environment

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Run the app

```bash
streamlit run app.py
```

Then open the local URL shown in the terminal, typically:

```text
http://localhost:8501
```

## Expected Data Format

The app expects a dataset containing these core columns:

| Column | Description |
|---|---|
| `order_id` | Unique order identifier |
| `date` | Order date |
| `revenue` | Revenue generated by the order |
| `customer_id` | Customer identifier |

The app can also map common aliases automatically, such as `order_number`, `purchase_date`, `sales`, `amount`, and `customer`.

## KPI Definitions

| KPI | Description |
|---|---|
| Revenue | Total sales recorded in the selected period |
| Revenue Growth % | Percentage change in revenue compared with the previous period |
| Orders | Total number of orders in the selected period |
| Order Growth % | Percentage change in order volume compared with the previous period |
| Unique Customer Growth % | Percentage change in unique customer count |
| Average Order Value (AOV) | Revenue per order |
| AOV Growth % | Percentage change in average order value |

## Example Workflow

1. Upload a CSV/Excel file.
2. Review the automatic schema mapping summary.
3. Check the cleaning report for invalid values or missing fields.
4. Select a trend interval: Daily, Weekly, Monthly, or Quarterly.
5. Explore KPIs and charts for business growth insights.

## Troubleshooting

- If upload fails, verify the file is valid CSV/Excel and not empty.
- If date parsing fails, check whether date values use a consistent format.
- If columns are not detected, ensure your data uses names similar to `order_id`, `date`, `revenue`, and `customer_id` or one of the configured aliases.
- If the app does not start, reinstall dependencies with:

```bash
python -m pip install -r requirements.txt
```
